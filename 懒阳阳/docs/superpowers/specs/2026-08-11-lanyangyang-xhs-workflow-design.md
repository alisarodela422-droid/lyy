# 懒阳阳小红书商务协作系统设计（飞书版）

日期：2026-08-11
状态：待用户审阅

## 1. 背景与目标

懒阳阳为小红书穿搭博主，账号定位为都市中女、轻奢、设计师女装风格，以地素 D'zzit、Edition 等品牌测评起号。商务人员与博主本人需要一套双人协作系统，覆盖品牌合作排期与内容选题灵感，且不能只在本机部署。

本次明确的目标：

1. 排期管理：管理每个品牌合作的寄样到货日期、拍摄日期、发布日期，避免撞期和遗漏。
2. 选题灵感：维护热点主题、话题 tag、品牌试穿机会，并新增「艺人近期热度穿搭」类型，筛选符合懒阳阳中女风格的品牌蹭流量。
3. 双人协作：商务用电脑、博主用手机，两人均可编辑查看。
4. 平台：使用飞书（多维表格 + 自动化）。
5. 数据源：热点数据先用免费公开榜单自动抓取；灰豚数据为付费版但无 API，作为人工补充源。

## 2. 用户与使用场景

用户 A（商务）：电脑端为主。负责品牌对接、排期录入、到货跟进、发布跟进、热点数据二次筛选、灰豚数据整理导入。

用户 B（博主懒阳阳）：手机端为主。负责确认拍摄档期、日常记录灵感、收藏艺人穿搭、反馈选题方向。

固定两人使用，不增加第三人，因此权限模型保持简单：两人对共享空间均有编辑权限。

## 3. 总体架构

系统由四部分组成：

1. 飞书多维表格：数据存储与视图，包括 4 张表。
2. 飞书自动化：定时提醒、状态变更通知，通过飞书消息触达两人。
3. 云端采集任务：GitHub Actions 定时运行脚本，抓取免费公开榜单，经飞书开放平台 API 写入「热点主题」表。
4. 人工录入：灰豚数据、艺人穿搭细节、品牌池维护，由商务或博主按模板补充。

数据表关系：

- 「灵感选题」关联「品牌库」和「热点主题」。
- 「热点主题」关联「品牌库」（艺人穿搭可对应多个中女风格品牌）。
- 「合作项目」独立，选题被采用后按合作流程进入排期。

## 4. 合作排期工作台

### 4.1 「合作项目」表字段

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| 品牌 | 文本 | 品牌名称 |
| 合作形式 | 单选 | 寄拍 / 置换 / 付费商单 / 自购 |
| 对接人 | 人员 | 品牌方对接人 |
| 联系方式 | 文本 | 微信或电话 |
| 寄样日期 | 日期 | 品牌寄出样品日期 |
| 预计到货 | 日期 | 预计到货日期 |
| 实际到货 | 日期 | 实际到货日期，用于逾期判断 |
| 拍摄日期 | 日期 | 拍摄档期 |
| 发布日期 | 日期 | 小红书发布截止日 |
| 平台 | 单选 | 小红书主号 / 小红书小号 / 其他 |
| 状态 | 单选 | 待寄样 / 在途 / 已到货 / 待拍摄 / 已拍摄 / 待发布 / 已发布 / 已取消 |
| 负责人 | 人员 | 商务或博主 |

| 发布链接 | 链接 | 发布后的笔记链接 |

| 创建人 | 人员 | 自动记录 |

### 4.2 状态流转

正常流程：待寄样 -> 在途 -> 已到货 -> 待拍摄 -> 已拍摄 -> 待发布 -> 已发布。

异常流程：任一状态可进入「已取消」，并保留备注说明原因。

### 4.3 视图

- 表格视图：默认，商务在电脑端批量维护。
- 拍摄日历：按拍摄日期展示，避免同日多场拍摄。
- 发布日历：按发布日期展示，避免发布撞期。
- 看板视图：按状态分组拖拽卡片。
- 甘特图：查看单个品牌从寄样到发布的时间线。

### 4.4 自动化规则

1. 每日 09:00：状态为「在途」且实际到货为空、预计到货已过或 3 天内到期，提醒商务跟进。
2. 每日 09:00：拍摄日期为明天的记录，提醒博主准备。
3. 每日 09:00：发布日期为明天的记录，提醒商务确认发布。
4. 记录更新时：状态或关键日期变化，自动通知共享群，保证两人信息同步。

### 5.4 艺人穿搭使用流程

1. 发现艺人热度穿搭后，在「热点主题」新建记录，类型选「艺人穿搭」，填写艺人、场合、穿搭描述、参考链接。
2. 商务判断其中出现的品牌是否属于中女风格，关联「品牌库」。
3. 合适的热点生成「灵感选题」，标记待选。
4. 确定采用后，进入拍摄排期，并在「合作项目」中建立记录。

## 6. 数据采集方案

### 6.1 免费公开榜单（自动）

采集源候选：微博热搜、百度热搜、抖音热榜。采集脚本按关键词粗筛穿搭、女装、品牌、艺人相关词条，写入「热点主题」表，类型标记为「品牌热点」或「平台话题」，来源标记对应榜单。

运行方式：

- GitHub Actions 定时任务，每日运行 1 次（默认 09:00，可调为早晚各 1 次）。
- Python 脚本抓取榜单，关键词匹配后调用飞书开放平台 API 写入多维表格。
- 飞书开放平台创建自建应用，授权多维表格读写；凭据保存在 GitHub Secrets。

容错要求：

- 任一数据源失败不影响其他数据源。
- 抓取失败保留已有数据，并向飞书共享群发送失败提醒。
- 榜单页面结构变化时，脚本需人工修复；这是公开网页抓取的固有风险。
- 脚本只负责采集和粗筛，人工负责二次筛选和补充内容。

### 6.2 灰豚数据（人工 / 半自动补充）

灰豚付费版无 API，采用人工整理导入：

1. 商务在灰豚查询小红书品牌榜、笔记热度、达人数据。
2. 导出或复制关键字段，按固定模板整理。
3. 通过飞书多维表格导入功能批量写入「品牌库」和「热点主题」。

灰豚导入模板字段：品牌、热度、涨粉情况、相关笔记、是否适合中女风格、备注。

### 6.3 艺人穿搭（人工为主）

免费榜单只能抓到「艺人 + 穿搭」相关的热搜词，具体造型内容需要人工补充。博主手机端看到合适内容可即时记录一条；商务电脑端补充品牌信息和排期。

## 7. 权限与协作

- 飞书空间共享给商务和博主，两人均授予编辑权限。
- 通过「负责人」「创建人」字段区分职责，不做复杂权限控制。
- 自动化通知统一发到两人的共享群。
- 数据备份：每周导出多维表格 Excel 存档，可通过自动化提醒执行。

## 8. 实施计划

阶段一：先可用

- 在飞书中创建 4 张表、字段、视图和自动化规则。
- 录入现有合作项目、品牌池和近期热点。
- 两人在手机端和电脑端联调使用。

阶段二：自动采集

- 创建飞书开放平台自建应用并配置权限。
- 编写榜单采集脚本。
- 部署 GitHub Actions 定时任务并配置凭据。
- 验证自动写入与失败告警。

阶段三：打磨

- 灰豚数据导入模板落地。
- 艺人穿搭检索视图（按艺人、品牌、场合筛选）。
- 月度复盘视图：发布数量、合作品牌、选题命中率。

## 9. 验收标准

1. 两人均可通过飞书手机端和电脑端编辑查看同一套数据。
2. 合作排期字段完整，状态流转可用，到货、拍摄、发布提醒按规则触发。
3. 热点主题至少有一个免费榜单数据源可每日自动写入，失败时有告警。
4. 艺人穿搭类型可录入，可按艺人、品牌、场合检索。
5. 灰豚数据可按模板批量导入。

## 10. 前置条件清单

- 飞书账号：建议使用免费团队版，两人加入同一组织。
- GitHub 账号：用于免费 GitHub Actions 定时任务。
- 飞书开放平台：需要创建自建应用并配置多维表格 API 权限。
- 共享群：用于自动化通知，商务和博主加入。
